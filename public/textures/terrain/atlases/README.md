# Baked terrain atlases

Generated by `npm run bake:terrain-atlases`, do not hand-edit.

Play and the editor load `color.ktx2` (and play `ao.ktx2`) via `loadBakedTerrainAtlases`
(`src/world/terrain/loaders/loadBakedTerrainAtlases.ts`). The PBR sources they are baked from live in
`assets-src/terrain/{biome}/` (see the README there); editor thumbnails are written to `../thumbs/`.
